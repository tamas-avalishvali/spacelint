# Whitespace Ninja

## What it does

Highlights unintended double spaces in real time and helps you keep your code clean and consistent.

## Why use it

Double spaces can make your code messy and hard to read. Whitespace Ninja highlights them instantly.

## Features

- Real-time detection of double spaces
- Customizable highlight color
- Works in any text or code file

## Settings

- `doubleSpaceHighlighter.highlightColor`: Background color for double space highlight (default: `rgba(255,0,0,0.3)`)
